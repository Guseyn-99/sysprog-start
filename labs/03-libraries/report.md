Система: Windows 11

## Библиотеки файла
Программа напечатала: libs.exe: sqrt(2) = 1.414214
Команда для списка библиотек файла: dumpbin /nologo /dependents libs.exe | findstr /i .dll
Библиотеки libs: KERNEL32.dll
Почему в списке нет отдельной математической библиотеки (или почему она есть): в Windows при сборке через MSVC функция sqrt берётся из стандартных системных библиотек времени выполнения, поэтому отдельная математическая DLL не показывается.
Где лежит интерпретатор Python (файл или библиотека): C:\Users\User\AppData\Local\Programs\Python\Python311\python.exe
