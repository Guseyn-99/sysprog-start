## Агент мониторинга компьютера

Проект объединяет системное программирование на C, взаимодействие с Python и автоматизацию обработки событий.

### Тема 1.1 — Ядро агента на C

**Каталог:** `agent/core/`

Реализовано:

- Структура `core_info` для хранения системной информации.
- Функция `core_get_info` для получения данных компьютера.
- Получение PID, количества логических процессоров, размера страницы памяти и имени компьютера.
- Проверочная программа `show_info.c`.
- Сборка динамической библиотеки `sentry_core.dll`.

### Тема 1.2 — Интеграция C и Python

**Каталог:** `agent/brain/`

Реализовано:

- Загрузка библиотеки `sentry_core.dll` через `ctypes`.
- Описание структуры `CoreInfo` на Python.
- Вызов функции C из программы Python.
- Получение системных данных и формирование JSON.

Пример вывода:

```json
{
  "event": "agent_started",
  "os": "win32",
  "pid": 12668,
  "cpus": 12,
  "page_size": 4096,
  "host": "TECNO-GUSEYN"
}
```

*PID приведён для примера и изменяется при каждом запуске.*

### Тема 1.3 — Автоматизация через n8n и Ollama

**Каталоги:** `agent/brain/`, `agent/n8n/`

Реализовано:

- Отправка системного события из `brain.py` через HTTP POST.
- Приём JSON с помощью Webhook в n8n.
- Вызов локального API Ollama через HTTP Request.
- Обработка информации нейросетевой моделью `qwen2.5:0.5b`.
- Экспорт сценария в `agent/n8n/agent-started.json`.

Схема взаимодействия:

```text
C (sentry_core.dll)
        ↓
Python (brain.py)
        ↓
HTTP POST / Webhook
        ↓
n8n
        ↓
HTTP Request
        ↓
Ollama (qwen2.5:0.5b)
        ↓
Ответ нейросети
```

**Статус:** локальная интеграция протестирована. Используется облегчённая модель `qwen2.5:0.5b`; отправка уведомлений по электронной почте пока не реализована.

## Запуск системного агента

### 1. Сборка C-библиотеки

Откройте **x64 Native Tools Command Prompt for VS 2022**.

Из корня репозитория выполните:

```cmd
cd agent\core
cl /nologo /W4 /LD core_info.c /Fe:sentry_core.dll
```

### 2. Запуск Python

Из корня репозитория:

```powershell
py .\agent\brain\brain.py
```

Программа собирает системную информацию и отправляет JSON в n8n.

**Для работы HTTP-интеграции необходимо предварительно запустить n8n** и импортировать или опубликовать сценарий `agent/n8n/agent-started.json`.

### 3. Запуск n8n

```powershell
npx.cmd n8n start
```

Локальный интерфейс доступен по адресу:

`http://localhost:5678`

Для обработки событий требуется запущенный Ollama с установленной моделью `qwen2.5:0.5b`.
