
# Мозг агента (Python)

`brain.py` загружает ядро через `ctypes`, вызывает функции C-библиотеки и получает сведения о системе.

## Тема 1.2 — C и Python вместе

| Файл | Что в нём |
|---|---|
| `brain.py` | Подключение `sentry_core.dll`, вызов `core_get_info` и вывод JSON |

Программа получает PID процесса, количество логических процессоров, размер страницы памяти и имя компьютера.

### Запуск на Windows

Сначала собрать DLL из папки `agent/core`:

```cmd
cl /nologo /W4 /LD core_info.c /Fe:sentry_core.dll
```

Затем из корня проекта выполнить:

```cmd
py agent\brain\brain.py
```
